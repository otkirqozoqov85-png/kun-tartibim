КУН ТАРТИБИМ — 1-ВЕРСИЯ

Файллар:
- index.html — илова интерфейси ва асосий функциялар
- manifest.webmanifest — телефонга ўрнатиш (PWA) маълумоти
- sw.js — кэш ва оддий офлайн очилиш
- icon.svg — илова белгиси

ҚАНДАЙ ИШГА ТУШИРИЛАДИ?
1. Папкани HTTPS қўллайдиган статик хостингга жойланг (масалан, GitHub Pages).
2. Сайтни Android телефонида Chrome ёки Edge орқали очинг.
3. «＋ Қўшиш» билан вазифалар киритинг, бўлим ва вақтни танланг.
4. «Ёқиш» тугмаси орқали браузер билдиришномасига рухсат беринг.
5. Браузер менюсида «Установить приложение» ёки «Добавить на главный экран»ни танланг.

ЭCЛАТМА ТЕХНИК ЧЕКЛОВИ:
- Бу версия вақтни саҳифа очиқ турганда текширади. Саҳифа/браузер ёпилганда, телефон батарея тежаш режимида бўлганда ёки Android фон жараёнларини тўхтатганда эслатмалар кечикиши ёки келмаслиги мумкин.
- Service Worker кэш ва офлайн очилиш учун; у ўз-ўзидан аниқ вақтда маҳаллий билдиришнома юборолмайди.
- Телефонда ишончли фон эслатмалари керак бўлса, кейинги босқичда push-сервер ва Web Push, ёки Android иловаси/маҳаллий alarm механизмидан фойдаланиш керак.
- Маълумотлар ҳозирча фақат шу браузер қурилмасида localStorage орқали сақланади; аккаунт ва қурилмалар ўртасида синхронлаш йўқ.

ТЕСТ:
- Вазифа қўшиш, таҳрирлаш ва ўчириш
- Бажарилди белгиси
- Бўлимлар бўйича фильтр
- Кунлик, душанба–жума, ҳафталик такрор
- JSON форматда маълумот экспорт қилиш
- Браузер билдиришномаси рухсати ва саҳифа очиқ пайтда вақтли эслатма
